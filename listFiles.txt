Memo: organisation des fichiers et commandes

Organisation des fichiers sur C:CODEBASE/Github et GitHub  ( /  sur le web !!)
LeFractiste.github.io/
├── .git/                 (Masqué par défaut)
├── .gitignore            (Votre fichier créant les règles d'exclusion)
├── index.html            (Page principale site GitHub)
├── style.css             (fichier css pour cet html - et le site ?)
├── Mandel_v2/            (Projet Mandelbrot, version V2 released, à conserver)
│   ├── Cargo.toml        (config cargo=Rust)
│   ├── index.html        (html pour git)
│   ├── app.js            (code applicatif pour le html, interface graphique)
│   ├── Mandelbrot.js     (business logic Mandelbrot)
│   ├── palette.js        (objet: business logic + I/F éditeur de palette 1024 couleurs)
│   ├── src/              (source Rust: lib.rs)
│   └── pkg/              (package Rust: mandel.wasm + mandel.js) à renommer M-Rust
│   └── target/           (fichiers temporaires de compilation Rust)
├── Mandelbrot/           (idem version en développement)               
├── NoCompile/            (mes vieux codes et tests et code généré non utlisé)

Commandes:
# Empaqueter tout le dossier (vérifier le CD directory !)
git add .

# Commiter la correction de structure
git commit -m "fix(): comment"

# Envoi vers GitHub
git push origin main


#special
git add path -f   #force l'ajout d'un répertoire/fichier, pour effacer un tag gitignore
git mv mandel-dev mandel_V3   #renomme un répertoire (avantage: garde les liens)
